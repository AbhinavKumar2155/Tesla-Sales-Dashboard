# 🚗 Tesla Sales Dashboard

An interactive Power BI dashboard designed to explore Tesla delivery, sales, regional, model, pricing, profit, and sustainability trends from 2015 to 2025.

This project transforms the Tesla deliveries dataset into a visual and interactive report that helps users understand performance patterns across different years, models, regions, and time periods.

## 📌 Project Overview

The **Tesla Sales Dashboard** is a Power BI project based on Tesla deliveries data from 2015 to 2025.

It provides an interactive way to explore delivery performance and related business metrics across:

- Years
- Tesla models
- Regions
- Months
- Quarters
- Pricing and range metrics
- Profit and sustainability indicators

The dashboard is designed to make historical trends easier to understand through clear visualizations and interactive filtering.

---

## ✨ Key Features

- 📈 Delivery trends over time using year-wise charts
- 🎯 KPI cards for summary metrics such as deliveries, revenue, cost, profit, and other available measures
- 🚘 Model-wise comparisons for deliveries, average price, range, and CO₂ savings
- 🌍 Regional analysis using map-based visualizations
- 💰 Profit comparison across regions
- 🔋 Sustainability analysis using CO₂ saved metrics
- 🎛️ Interactive slicers for model, month, quarter, and year
- 📊 Comparative charts for Tesla models and regional performance
- 🔎 Visual exploration of patterns and changes across the available dataset

> The insights presented in the dashboard are based on the fields and records available in the provided Tesla deliveries dataset.

## ▶️ How to Run the Project

1. Clone or download this repository:

   ```bash
   git clone https://github.com/AbhinavKumar2155/Tesla-Sales-Dashboard.git
   ```

2. Open the project folder.

3. Launch the Power BI file:

   ```text
   Tesla_Sales_Dashboard.pbix
   ```

4. Open the file using **Microsoft Power BI Desktop**.

5. If Power BI requests the source data, select:

   ```text
   tesla_deliveries_dataset_2015_2025.csv
   ```

6. Use the available slicers and report navigation buttons to interact with the dashboard.

> Make sure the CSV file remains available if the Power BI report requires a data refresh.
